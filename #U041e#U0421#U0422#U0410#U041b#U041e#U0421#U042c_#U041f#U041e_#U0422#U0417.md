# Статус выполнения ТЗ

## Реализовано в проекте

- Бесплатные preview-видео пяти курсов подключены через данные уроков и открываются в центрированной popup-модалке.
- Плеер поддерживает постер, запуск одним кликом, паузу, перемотку, громкость, fullscreen и `preload="metadata"`.
- После окончания бесплатного урока модалка закрывается и появляется плавающий CTA покупки.
- Нажатие на закрытый урок или закрытый материал показывает CTA и не раскрывает защищённый URL.
- CTA содержит цену, кнопку покупки и закрытие; после закрытия повторно появляется только по новому событию.
- Платёжная ссылка удалена из JSX и перенесена в данные конкретных курсов (`paymentUrl`).
- Оплата открывается на текущей защищённой странице MONETA / PayAnyWay; секреты платёжной подписи во фронтенд не добавляются.
- Если `paymentUrl` отсутствует, кнопка использует безопасный fallback — письмо на `info@askhow.ru` с названием курса.
- Длинная программа раскрывается и сворачивается без дублей; при сворачивании выполняется мягкий возврат только если пользователь уже ниже первых шести уроков.
- Материалы выводятся только из `course.materials`, поддерживают тип, URL, блокировку, размер, открытие и скачивание.
- Пустые или некорректные секции материалов скрываются.
- Добавлены безопасные события аналитики: просмотр курса, запуск/завершение preview, раскрытие уроков, закрытый урок/материал, показ CTA, покупка и открытие материала.
- Аналитика использует существующий `gtag`/`dataLayer`, если он доступен, и не ломает страницу при ошибке.
- Модальные окна выводятся через портал в `document.body`, поэтому не обрезаются анимацией страницы.

## Нужны внешние данные

- Программы и preview-видео для курсов, у которых список уроков пока отсутствует в исходных данных каталога.
- Реальные материалы курсов: название, тип, публичный URL или правило доступа и размер. До их добавления секция по требованиям ТЗ скрыта.
- Уникальные платёжные ссылки, если PayAnyWay выдаёт отдельную ссылку для каждого курса. Сейчас каждому платному курсу назначен существующий рабочий checkout из предыдущей версии проекта.

## Нужен доступ к серверу

- Загрузить содержимое архива в `/srv/frontend`.
- Выполнить `npm install` при необходимости и `npm run build`.
- Перезапустить только процесс `frontend` в PM2 и выполнить `pm2 save`.
- Проверить PM2, фактический порт, nginx и ответы `catalog.askhow.ru`.
- Финально проверить реальные клики в браузере на ширинах 320, 375, 768, 1024, 1440 и 1920 px уже на серверной сборке.

Локально выполнены ESLint для изменённых файлов, production-сборка, проверка структуры данных и проверка всех пяти MP4 через `ffprobe`.
