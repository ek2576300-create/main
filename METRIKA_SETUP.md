# Яндекс Метрика

Счётчик: `112288061`

В проект подключены цели:

- `course_open` — открытие страницы курса;
- `preview_start` — запуск бесплатного урока;
- `preview_complete` — досмотр бесплатного урока;
- `buy_click` — клик по кнопке покупки / открытие окна оплаты;
- `payment_redirect` — клик «Перейти к оплате» перед переходом на платёжную страницу.

Основной код счётчика находится в `index.html`.
Отправка целей находится в `src/utils/analytics.js`.
События вызываются на странице курса `src/pages/CoursePage.jsx`.

После загрузки проекта на сервер обязательно пересобрать фронтенд:

```bash
cd /srv/frontend
npm install
npm run build
pm2 restart frontend
pm2 save
```

Проверка целей:

Откройте сайт с параметром `?_ym_debug=2`, затем DevTools -> Console и выполните нужные действия.
